# Ranking Pro

Reputação verificada por QR — Shark Mode MVP.

**Repositório público.** GitHub: `leandrogrochamedia/RankingPro`

**Site (GitHub Pages):** https://leandrogrochamedia.github.io/RankingPro/

## Stack

- HTML / CSS / JavaScript estático
- Supabase REST
- GitHub: https://github.com/leandrogrochamedia/RankingPro

## Fluxo principal

1. **Splash** → Entrar → login → seletor de perfil  
2. **Cliente** → avaliar (QR) ou buscar profissionais  
3. **Profissional** → dashboard + QR de avaliação verificada  
4. **Estabelecimento** → dashboard de reputação da equipe (marketplace congelado — DEV only)
